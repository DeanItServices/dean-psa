- **Plan critique run** (2 background agents: pre-mortem risk analysis + assumption hunting) before finalizing. Verdict: REWORK -- 2 CRITICAL + 4 HIGH findings, all fixed via plan revision prior to execution:
  - **04-01's raw-SQL partial-index application method invented non-existent Prisma CLI capability** (re-running `migrate dev` or a line-scoped `prisma db execute --schema` on an already-applied migration doesn't work in Prisma 7).   - **`generateInvoice` had a race window allowing two concurrent invoice runs to double-bill the same time entries.** Fixed: added a transaction-scoped re-check of `invoiceLineItemId IS NULL` on the exact consumed entries immediately before stamping, with a row-count verification that rolls back and returns a retry error on mismatch.
