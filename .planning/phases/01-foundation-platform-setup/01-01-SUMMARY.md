## Root cause / blocker

Environment Node.js version is **v20.0.0**. Next.js 16.3.3 (the version resolved by `create-next-app@latest` at execution time) hard-requires **Node >=20.9.0** and refuses to run `next build`, `next dev`, or `next typegen` below that version — this is enforced by the `next` CLI binary itself, not a soft warning. This also explains why `shadcn@latest` (and all versions >=3.0.0) crash outright: their dependency chain (`execa`, `undici`, `@inquirer/*`) requires Node >=20.5.0–20.17.0.

This is an execution-environment constraint, not a code defect. Fixing it requires upgrading the system Node.js installation (a winget-available upgrade to 22.23.2 was confirmed available but not installed, since modifying system-level tooling outside this plan's `files_modified` scope and without explicit authorization is out of bounds for this execution).
