<objective>
Make the database, not the JWT, authoritative for authorization — so deactivating a user or changing their role takes effect immediately instead of up to eight hours later.

Purpose: `getCurrentUser()` (`src/lib/session.ts:14`) is today `return (await auth())?.user ?? null` — zero database queries, and the JWT carries `role`, so a role edit is exactly as stale as a deactivation. This is the highest-leverage change in the phase: one edit at the choke point all 25 importers already funnel through.
Output: Modified `src/lib/session.ts`, `src/auth.ts`, `src/app/(dashboard)/layout.tsx`, `src/app/api/qbo/connect/route.ts`, `e2e/fixtures.ts`.
</objective>
