- Do not read env inside the request path on every call — parse once at module scope. Under
  Node that is still runtime-read (process start), which is what the requirement asks for.
- Do not change the limiter's algorithm, the `getClientIp()` null-skip behaviour, the
  `/login` POST classification, or the matcher.

Implementation sequence:
1. Read `src/proxy.ts` in full, and `08-01-SUMMARY.md` to confirm the runtime claim.
2. Add a small parse helper, e.g.
   `function envInt(name: string, fallback: number): number`. It reads `process.env[name]`,
   returns `fallback` when unset/empty, parses with `Number.parseInt(value, 10)`, and returns
   `fallback` when the result is not a finite integer `> 0`. On a rejected value it logs once
   at module scope — `console.warn` naming the variable, the offending value, and the default
   applied — so a typo is visible in container logs instead of silently weakening a control.

   limit governs.

   and a float. Record the observed behaviour in the summary.
