<objective>
Make ticket deletion admin-only, refuse it when the ticket's time is already invoiced, and leave
behind a docstring that describes what the function actually does.
</objective>

<context>
Read `.planning/phases/09-verification-debt-closure/09-CONTEXT.md` and
`.planning/specs/09-verification-debt-closure-spec.md` (sections 3.1-3.5) before starting.

WHY THIS IS NARROWER THAN "WIRE UP A BUTTON". `TimeEntry.ticket` is `onDelete: Cascade`, so
deleting a ticket destroys every time entry logged against it. `TimeEntry.invoiceLineItem` is
`onDelete: SetNull`, so the *line item survives*. An invoice therefore keeps its total while
losing the time records that justify it — silent billing-history corruption, reachable from a UI
that does not exist yet. (Symbols, not line numbers: ROADMAP and the exploration doc both cite
stale positions for these relations. Find them in `model TimeEntry`.)

FILE OWNERSHIP. 09-01 runs in parallel and owns `e2e/**` and `playwright.config.ts`. You own
`src/lib/actions/tickets.ts` and nothing else. The confirmation dialog and the E2E cases are
09-03's work — do not add UI, and do not write tests here.
</context>
