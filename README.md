# MSP PSA

An in-house Professional Services Automation (PSA) platform built for internal use at the MSP. Built with Next.js (App Router), TypeScript, Tailwind CSS, and shadcn/ui.

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

Docker Compose and database setup are documented in a future update once Plan 01-02 lands.
